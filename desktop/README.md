# GCMS Pilot

本地 AI 内容驾驶舱 —— macOS 桌面客户端（Tauri 2 + Svelte 5）。导入 gcms 平台技能包，
用本地 Claude Code / Codex / Grok 客户端，或自备 API Key 的模型服务，为平台下的多个站点生产内容。
API 服务由对应供应商独立计费，不使用本地客户端的订阅额度。

## 功能

- **导入技能包**：支持嵌密钥包与原始包（原始包导入时提示粘贴 `gcmsp_` 密钥）。
  密钥只进 **macOS 钥匙串**，绝不落盘、绝不进 WebView。
- **站点发现**：读取平台发现契约，展示所有可管理站点（含 Logo / 域名）。
- **本地大脑**：自动检测 claude / codex CLI 的安装与登录状态；未登录一键「去授权」
  （打开终端跑官方登录命令，自动带上系统代理）。
- **API 服务**：设置 → API 服务 → 添加。支持 OpenAI Responses、Anthropic Messages 和
  OpenAI 兼容 Chat Completions，可配置多个独立账号、读取或手填模型 ID；接入会话、技能、
  定时任务与托管的共同模型选择器。密钥只存系统凭据库，删除连接需确认。
- **API 用量与账单**：展开 API 连接下的「用量与账单」，单独配置查询凭据后手动刷新。
  官方 OpenAI / Claude 支持组织账户本月、今日费用及本月对话 token 用量，按 UTC 统计，
  不是仅此连接或 Pilot 的消费；服务商报表可能延迟。余额暂不支持查询，可打开服务商账单。
- **流水线**：写作 → 可选「AI 主编终审」（替代人工审核）→ 产出策略（草稿 / 直接发布 /
  定时发布，定时由 gcms 服务端到点自动发）。
- **三种任务**：单篇、批量（自动拆成互不重复的多篇）、新站建设（站点资料 + 导航 + 种子内容）。
- **任务台**：运行历史 + 待人工处理队列（终审未通过 / 无终审的草稿），可跳到 gcms 后台处理。
- **远程文件传输**：工具栏统一为「传输」，点击查看上传、下载的进度与最近 100 条结束记录，
  可上传文件、下载所选、取消正在传输的项目，或在 Finder 中显示已完成的下载。记录保存在本机，
  清除记录不会删除文件；应用重开时未结束的记录标为中断，不自动重传。
  macOS 可一次拖到 Finder / 桌面，系统文件图标与文件名跟随指针，松手后后台下载，无需二次拖动。
  也可从 Finder 将本地文件或文件夹一次拖入远程文件面板上传（包括大文件）；拖到真实子目录行时，
  该目录高亮并成为上传目标，拖到空白处或普通文件行则上传到当前目录。上传进度、取消和结果统一在「传输」查看。
  本地路径绑定实际拖放序列并校验文件，不读取剪贴板残留；聊天附件的拖入行为不变。
  下载不删除远端文件、不覆盖本地同名内容；目录含软链接或特殊文件时请使用「打包下载」。
  上传取消会停止后续写入，但远端已写入的部分会保留。Windows / Linux 可在「传输」中选择本地保存位置。
- 关窗隐藏到托盘，后台任务继续跑；完成时系统通知。

## 开发

```bash
npm install
npm run tauri dev
```

依赖：Rust ≥ 1.88、Node ≥ 20；运行模型时需要至少一个已登录的本地客户端或已配置的 API 服务。

### API 服务边界

- “测试连接”只验证认证及模型列表，不会付费生成内容，也不代表已验证工具能力。模型需支持工具调用。
- 原生 API 执行支持流式文本、技能文件、GCMS 和 SSH 工具。图片 / PDF 识别、Cloudflare 授权操作暂用本地客户端。
- API Key 不传给工具子进程。计划模式禁止写入；询问 / 自动模式下通用本机命令逐次确认；
  全自动模式允许用户已授权的本机命令，**不是操作系统级文件沙箱**。
- 工具执行前持久化中断状态，全部工具结果原子保存后形成安全检查点。已记录的结果可在原会话继续，
  旧 Claude 会话需通过完整调用 / 结果配对校验才恢复；有未确认工具结果的中断仍需核对后新建会话，不自动重放工具。
  Claude 明确返回 `max_tokens` 时丢弃当次不完整工具调用，最多按原输出上限重新生成一次，并计入两次请求用量。
  不自动重试断网、鉴权失败或其他错误，不自动增加已保存连接的输出上限；失败工具也可能有副作用。
  新建 Claude 连接默认单次输出 32768 token（含思考和工具参数），其他连接默认不变；旧连接保留原设置，
  可在「高级设置 → 单次最大输出 token」按模型支持范围调整。重试仍触顶时明确提示，不要求重建已安全保存的会话。
  Claude 思考签名与系统说明、工具定义及历史前缀绑定：截断恢复提示只追加为新消息，不改写系统说明。
  升级或工具定义变更时，仅一次性移除失效的旧思考块，保留全部正文及工具调用 / 结果；前缀未变则原样保留思考历史。
  超过上下文或调用上限会明确停止，不静默截断历史。
- API 连接和密钥暂不随配置包迁移；迁移后需重新添加连接并为相关会话、任务选定模型。
- 账单查询凭据与模型调用 Key 独立保存在系统凭据库，只用于官方报表接口，不用于模型生成。
  更改连接的接口地址 / 协议或删除连接会移除其查询凭据；不跟随配置导出。
  OpenAI 使用 Admin API Key；Claude 使用 Admin API Key 或官方允许的组织级查询凭据，
  普通 workspace 模型 Key 无法查询。查询报错显示不可用，绝不将失败当成零余额或零消费。
- 账单数据来自 [OpenAI Usage / Costs](https://developers.openai.com/cookbook/examples/completions_usage_api)
  与 [Claude Usage and Cost API](https://platform.claude.com/docs/en/manage-claude/usage-cost-api)。
  Claude 成本报表不包含 Priority Tier；OpenAI token 统计来自 completions 用量端点，不代表所有 API 产品。
  兼容协议不代表兼容账单接口：尚未适配的第三方服务明确显示「暂不支持查询」。

## 尚未接入（对外分发前的前置）

以下按冻结方案属于对外分发阶段，v0 自用不含，需要外部凭据/仓库，未在本仓接线：

- **自动更新**：`pilot-v*` tag 触发独立 `pilot-release.yml` → 独立 `ccvar/gcms-pilot-releases`
  仓库（**不可**与 `gcms-releases` 混用，否则两个 updater 的 `releases/latest` 互相顶掉）。
  需要 `PILOT_RELEASES_TOKEN` PAT + tauri updater 的独立 ed25519 签名密钥
  （`tauri signer generate`，与 gcms 的 RSA 发布密钥无关）。
- **代码签名 / 公证**：Apple Developer 证书 + notarytool。

## 安全 / 合规要点

- 密钥仅存 macOS 钥匙串（`keyring-core` + `apple-native-keyring-store`）。
- 取消任务时对整个进程组 SIGKILL，避免 node/bash 孙进程带着密钥继续写 CMS。
- 直接发布无终审时有显式风险提示；默认策略为「草稿」。
